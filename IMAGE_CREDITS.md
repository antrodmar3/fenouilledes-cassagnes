# Créditos de imágenes

Esta primera versión no utiliza fotografías de terceros. Las portadas de cada día son placeholders abstractos generados con CSS y están rotuladas como provisionales.

La tarjeta social `public/og.png` es un recurso original generado para este prototipo con la herramienta de generación de imágenes de OpenAI (31 de julio de 2026). No representa una ubicación geográfica exacta y se usa únicamente como identidad visual provisional.
